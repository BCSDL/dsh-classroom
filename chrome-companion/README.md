# Chrome 字幕助手

1. 在 Chrome 的扩展管理页打开“开发者模式”，选择“加载已解压的扩展程序”，选择本目录。
2. 从 DSH `/classroom/watch` 开始标签页采集，复制连接码。
3. 切换到实际的视频标签页，点击“DSH 课堂字幕助手”，粘贴连接码并连接。
4. 回 DSH 可查看字幕、暂停/跳转/倍速的进度锚点；结束采集时配对自动失效。

浏览器安装与屏幕共享的授权由用户完成。仅在点击后读取当前连接标签页里的可见字幕和视频进度，不读取 cookies、历史、登录数据或媒体下载链接。字幕兼容性取决于播放器；优先读取原生 textTracks 的 activeCues，其他播放器会尝试可见字幕元素。没有可读字幕时仍可通过播放音频转写。

连接码含只允许向一条本地记录写入字幕/时间的临时凭据。不要把它发给别人，也不要公开在 GitHub。浏览器或 DSH 重启后重新连接。
